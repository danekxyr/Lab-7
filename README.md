# Лабораторная работа № 7

* **Студент:** Пылинский Даниил Максимович
* **Группа:** ПИ 1-1
* **Тема:** Одномерные массивы и статистика элементов

## Назначение файлов проекта

* **`main.c`** — ввод одномерного массива размером `n` (`1..100`) со значениями от `-1000` до `1000`, вывод массива, суммы, среднего арифметического и количества положительных, отрицательных и нулевых элементов.
* **`self.c`** — копирование элементов массива `a` в новый массив `b` с заменой отрицательных значений на `0`, сохранением исходного массива `a`, подсчётом числа замен и суммы элементов `b`.
* **`tests.txt`** — протокол обязательных тестов с входными данными, ожидаемыми и фактическими результатами для обеих программ.

## Команды сборки (PowerShell / Bash)

```bash
gcc -Wall -Wextra -std=c11 main.c -o lab7_main
gcc -Wall -Wextra -Wpedantic -std=c11 self.c -o lab7_self
```

## Пример запуска

### Основная программа (`main.c`)
Ввод:
```text
5
4 -2 7 0 3
```
Вывод:
```text
Array: 4 -2 7 0 3
Sum = 12
Average = 2.40
Positive = 3
Negative = 1
Zero = 1
```

### Самостоятельная работа (`self.c`)
Ввод:
```text
5
4 -2 7 0 -3
```
Вывод:
```text
Array a: 4 -2 7 0 -3
Array b: 4 0 7 0 0
Replacements = 2
Sum b = 11
```
